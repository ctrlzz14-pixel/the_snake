# Изгиб Питона

Учебная игра «Змейка» на Python и Pygame. Змейка двигается по полю
640×480 пикселей, ест яблоки и становится длиннее. Края поля проходимые.
Если змейка встречает себя, она возвращается в начало поля, и игра
продолжается.

## Технологии

- Python 3
- Pygame 2.5.2
- pytest
- flake8

## Установка и запуск

```bash
git clone https://github.com/ctrlzz14-pixel/the_snake.git
cd the_snake
python -m venv venv
```

Активируйте окружение.

Windows:

```bat
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

Установите зависимости и запустите игру:

```bash
pip install -r requirements.txt
python the_snake.py
```

## Управление

| Клавиша | Действие |
|---------|----------|
| ↑ | Движение вверх |
| ↓ | Движение вниз |
| ← | Движение влево |
| → | Движение вправо |

Закрытие окна завершает игру.

## Основные классы и их назначение

- `GameObject` — базовый класс для игровых объектов. Хранит позицию и цвет.
- `Apple` — яблоко. Выбирает свободную клетку и рисуется на поле.
- `Snake` — змейка. Хранит длину и цепочку клеток, двигается и может
  вернуться в начало после столкновения с собой.

Клавиши обрабатывает `handle_keys()`, а игровой цикл находится в `main()`.

## Запуск тестов

```bash
pytest
```

Тесты проверяют классы, константы и запуск `main()`.
Стиль кода можно проверить командой `flake8`.
