# Изгиб Питона

Учебная игра «Змейка» на Python и Pygame. Змейка движется по сетке
640×480 пикселей, собирает яблоки и увеличивается. Границы поля являются
проходимыми: вышедший за край сегмент появляется с противоположной стороны.
При столкновении головы с собственным телом змейка сбрасывается в начальное
состояние, и игра продолжается.

## Технологии

- Python 3
- Pygame 2.5.2
- pytest для автотестов
- flake8 для проверки стиля кода

## Возможности игры

- движение по сетке в четырёх направлениях;
- проход через границы игрового поля;
- поедание яблок и увеличение длины змейки;
- появление яблока только в свободной клетке;
- запрет разворота на 180 градусов;
- сброс змейки после самоукуса без завершения игры;
- отрисовка клеток с цветом границы.

## Управление

| Клавиша | Действие |
|---------|----------|
| ↑ | Движение вверх |
| ↓ | Движение вниз |
| ← | Движение влево |
| → | Движение вправо |

Закрытие окна завершает игру. Разворот на 180 градусов игнорируется.

## Описание классов

### `GameObject`

Базовый класс игровых объектов. Хранит `position` — координаты центра
экрана — и `body_color`. Метод `draw()` задаёт общий интерфейс отрисовки и
не выполняет рисующих действий.

### `Apple`

Наследуется от `GameObject`. Цвет задаётся константой `APPLE_COLOR`.
При создании и после поедания вызывает `randomize_position()`, который
выбирает случайную клетку сетки и исключает клетки, занятые змейкой. Если
свободных клеток нет, позиция яблока не меняется, что исключает
бесконечный цикл. Метод `draw()` рисует яблоко и границу его клетки.

### `Snake`

Наследуется от `GameObject`. Основные атрибуты:

- `length` — текущая длина;
- `positions` — список координат сегментов от головы к хвосту;
- `direction` — текущее направление;
- `next_direction` — направление, выбранное игроком;
- `last` — координаты удалённого хвостового сегмента.

Начальная позиция — центр поля, начальное направление — `RIGHT`.

Методы:

- `get_head_position()` возвращает координаты головы;
- `update_direction()` применяет выбранное направление и блокирует
  разворот на 180 градусов;
- `move()` добавляет новую голову через `insert(0, ...)`, удаляет хвост
  через `pop()`, использует `%` для прохода через границы и сохраняет
  удалённый сегмент в `last`;
- `draw()` отрисовывает голову и тело, а затем стирает последний сегмент;
- `reset()` возвращает змейку к длине 1, центру поля и направлению
  `RIGHT`.

## Игровой цикл

Функция `main()` создаёт объекты `Snake` и `Apple`, затем в цикле:

1. ограничивает частоту через `clock.tick(SPEED)`;
2. обрабатывает события клавиатуры и закрытие окна;
3. обновляет направление и перемещает змейку;
4. проверяет поедание яблока, увеличивает длину и перемещает яблоко;
5. проверяет самоукус и при необходимости вызывает `reset()`;
6. очищает экран, отрисовывает яблоко и змейку;
7. обновляет отображение через `pygame.display.update()`.

Функция `handle_keys()` обрабатывает `pygame.QUIT` и `pygame.KEYDOWN`,
сохраняет направление в `next_direction` и запрещает разворот на 180
градусов.

Вызов `main()` находится под защитой `if __name__ == '__main__':`, поэтому
импорт модуля не запускает игру.

## Запуск автотестов

```bash
pytest
```

Тесты проверяют структуру классов, наличие констант и функций, типы
`screen` и `clock`, а также то, что `main()` запускается без исключений.

## Проверка стиля кода

```bash
flake8
```

Настройки проверки находятся в `setup.cfg`. В проекте используются
докстринги для классов и методов и соблюдается ограничение длины строки.
